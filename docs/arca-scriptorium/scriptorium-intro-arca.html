SCRIPTORIUM 2.0
Obsidian에서 정리하고, 필요한 문단만 번역하고,
RisuAI 캐릭터에 바로 연결하는 로어북 작업실
Markdown 관리  문단별 부분 번역  RisuAI 동기화
로어북을 하나의 편집창이 아니라 프로젝트로
RisuAI 로어북이 커질수록 항목을 찾고, 고치고, 번역본까지 맞춰 관리하기가 번거로워집니다. Scriptorium은 로어북을 Obsidian의 Markdown 문서와 폴더로 나누어 관리하고, 수정된 문단만 골라 번역한 뒤 RisuAI에 동기화하는 플러그인입니다.
다운로드
OBSIDIAN PLUGIN + RISUAI PLUGIN
Obsidian 문서와 Scriptorium 대시보드
01 · ORGANIZE
문서처럼 쓰고, 폴더처럼 정리하기
인물 · 장소 · 세계관을 익숙한 Obsidian 방식으로 관리합니다.
각 로어북 항목은 하나의 Markdown 문서가 됩니다. 본문은 평범하게 작성하고, 제목·키워드·항상 활성화·삽입 순서 같은 정보는 문서 속성으로 관리합니다. 항목이 많아지면 Obsidian의 표 편집기에서 메타데이터만 한눈에 고칠 수도 있습니다.
프로젝트 파일 구조 Markdown 로어북 문서
여러 문서의 로어북 속성을 한 번에 보는 표 편집기
02 · START
프로젝트 등록은 폴더 하나면 끝
1명령 팔레트에서 Scriptorium: 프로젝트 등록을 실행합니다.
2원문 Markdown이 들어 있는 최상위 폴더를 선택합니다.
3등록된 폴더의 문서를 열면 오른쪽 대시보드가 프로젝트를 자동으로 따라갑니다.
① 프로젝트 등록 명령 ② 루트 폴더 선택
03 · TRANSLATE
바뀐 문단만 골라서 번역
긴 문서를 통째로 다시 번역할 필요가 없습니다.
원문을 수정하면 대시보드가 추가·수정·삭제·이동·분할·병합·키워드 변경을 문단 단위로 찾아냅니다. 번역할 항목만 체크하고 번역 실행을 누르면 선택한 부분만 번역됩니다. 원문과 번역본을 동시에 고쳐 충돌이 생긴 경우에는 수동 번역을 유지할지 AI 번역으로 교체할지도 직접 선택할 수 있습니다.
프로젝트별 프롬프트와 어휘 사전 변경 문서와 번역 대기 항목 선택
번역 품질을 맞추는 두 가지 설정
번역 프롬프트 · 작품별 문체와 번역 원칙을 지정합니다.
어휘 사전 · 한 줄에 원문 = 번역어 형식으로 적습니다. 요청 내용과 관련된 항목만 골라 전달하므로 사전이 길어져도 불필요한 항목을 매번 넣지 않습니다.
공용 번역 프롬프트 · 어휘 사전 · OpenAI 호환 API 설정
04 · CONNECT
RisuAI 캐릭터와 프로젝트 연결
로컬에서는 빠르게, 필요하면 릴레이로 모바일까지.
Obsidian 설정에서 로컬 스냅샷 서버를 켜고 RisuAI에 scriptorium.js를 JavaScript 플러그인으로 가져옵니다. RisuAI 채팅의 스크립토리움 버튼을 열어 프로젝트를 고르면 현재 캐릭터와 연결됩니다. 이후에는 설정한 주기마다 변경된 문서만 확인하고 반영합니다.
Obsidian 로컬 서버 · 릴레이 설정
연결 상태와 캐릭터-프로젝트 매핑 로컬 · 릴레이 · Description 설정
설치 및 첫 연결 순서 펼쳐보기
1. Obsidian 플러그인 폴더에 main.js, manifest.json, styles.css를 넣고 Scriptorium을 활성화합니다.
2. 프로젝트 폴더를 등록하고 번역 API 주소·모델·SecretStorage의 API 키를 설정합니다.
3. 로컬 서버를 켭니다. 기본 주소는 127.0.0.1:27124입니다.
4. RisuAI에 scriptorium.js를 가져오고, 원하는 캐릭터와 프로젝트를 연결합니다.
로컬 연결과 릴레이의 차이 펼쳐보기
로컬 연결 · 같은 PC의 Obsidian과 RisuAI를 직접 연결합니다. 데스크톱에서 간단하고 빠르게 사용할 때 적합합니다.
릴레이 연결 · 로컬 릴레이 스크립트(relay/relay.mjs)에 최신 스냅샷을 올려 같은 머신의 RisuAI가 가져가게 합니다. 양쪽에 같은 릴레이 주소·채널·토큰을 입력해야 합니다.
