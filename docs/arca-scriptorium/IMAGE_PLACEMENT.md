## 게시 전 확인

- 이미지가 들어갈 `<td>`는 가이드 규칙에 맞춰 완전히 비워 두었습니다.
- HTML 소스에서 `<img>`를 직접 넣기보다 아카라이브 에디터에 이미지를 붙여넣어 CDN 업로드를 거치는 편이 안전합니다.
- 모든 이미지 칸의 배경을 `#282828`로 통일해 이미지 높이 차이로 남는 영역이 덜 눈에 띄게 했습니다.
- 상단 다운로드 버튼은 제공받은 Proton Drive 주소에 연결했습니다.
